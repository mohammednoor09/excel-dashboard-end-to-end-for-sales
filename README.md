# African Sales Dashboard

An end-to-end Excel data analytics project focused on analyzing sales performance through an interactive dashboard.

## 📊 Dashboard Preview

![African Sales Dashboard](./Screenshot%202026-09-16%20205909.png)

## 📌 Key Metrics

* Total Revenue
* Total Profit
* Total Units Sold
* Revenue by Country
* Profit by Product

## 🛠️ Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Data Analysis
* Dashboard Visualization

## 📈 Project Overview

This project analyzes sales data and presents key business insights through an interactive Excel dashboard. It includes KPI cards, PivotTables, charts, and product/country-level analysis.

**Currency:** Indian Rupee (₹)
